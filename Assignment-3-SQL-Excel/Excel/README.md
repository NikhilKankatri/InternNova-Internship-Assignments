
# Assignment 3 – SQL & Excel for Data Analytics

## Internship
InternNova – Python and Data Analytics Internship

## Week 3 Assignment

**Topics:** SQL and Microsoft Excel for Data Analytics

**Duration:** 7 Days

**Total Marks:** 100

## Objective
To develop practical skills in SQL and Microsoft Excel for data analytics, including database operations, data retrieval, filtering, sorting, aggregate functions, joins, subqueries, Excel formulas, lookup functions, Pivot Tables and charts.

## SQL Tasks
1. Introduction to Databases and SELECT Statement
2. WHERE, ORDER BY and Aggregate Functions
3. GROUP BY and HAVING
4. SQL Joins
5. SQL Subqueries

## Excel Tasks
6. Data Formatting, Sorting and Filtering
7. Conditional Formatting and Excel Functions
8. VLOOKUP and XLOOKUP
9. Pivot Tables and Charts

## Technologies Used
- SQL
- SQLite
- Python
- Microsoft Excel

## Folder Structure
- SQL – SQL scripts, database and Python execution file.
- Excel – Excel workbook used for analysis.
- Screenshots – Screenshots of SQL and Excel outputs.
- Report – Final assignment PDF report.

## Learning Outcomes
- Write SQL queries to retrieve and analyze data.
- Apply filtering, sorting and aggregate functions.
- Perform GROUP BY, HAVING, JOIN and subqueries.
- Use Excel formulas and conditional formatting.
- Apply VLOOKUP and XLOOKUP.
- Create Pivot Tables and charts.
