
# SQL – Assignment 3

This folder contains the SQL scripts, SQLite database and Python execution file used for Week 3 of the InternNova Data Analytics Internship.

## Files Included

| File | Description |
|---|---|
| 00_setup_database.sql | Creates and prepares the database and tables. |
| company.db | SQLite database file. |
| run_sql.py | Python script for executing SQL queries. |
| task1_select.sql | SQL SELECT queries. |
| task2_where_orderby_aggregates.sql | WHERE, ORDER BY and aggregate functions. |
| task3_groupby_having.sql | GROUP BY and HAVING queries. |
| task4_joins.sql | SQL JOIN operations. |
| task5_subqueries.sql | SQL subqueries. |
