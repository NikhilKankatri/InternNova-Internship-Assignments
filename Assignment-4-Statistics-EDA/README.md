
# Assignment 4 – Statistics, Data Visualization & Exploratory Data Analysis (EDA)

## Internship
InternNova – Python and Data Analytics Internship

## Week 4 Assignment

**Duration:** 1 Week (7 Days)

**Total Marks:** 100

## Objective

To develop practical skills in Statistics, Data Visualization and Exploratory Data Analysis (EDA) using Python. This assignment focuses on statistical calculations, data visualization, data cleaning, correlation analysis, identifying outliers, generating insights and providing business recommendations.

## Tasks Covered

### Task 1: Statistical Analysis – Mean, Median & Mode (10 Marks)
- Calculate Mean, Median and Mode.
- Display statistical results.
- Explain the measures of central tendency.

### Task 2: Variance & Standard Deviation (10 Marks)
- Calculate Variance.
- Calculate Standard Deviation.
- Understand data spread and variability.

### Task 3: Correlation & Probability Basics (10 Marks)
- Calculate correlation between numerical variables.
- Identify positive, negative or weak relationships.
- Create and calculate a real-world probability example.

### Task 4: Outlier Detection (10 Marks)
- Identify potential outliers.
- Apply an appropriate outlier detection method.
- Understand the impact of outliers on data analysis.

### Task 5: Matplotlib Visualization (15 Marks)
Create the following visualizations:
- Line Chart
- Bar Chart
- Pie Chart
- Histogram
- Scatter Plot

### Task 6: Seaborn Visualization (15 Marks)
Create the following visualizations:
- Count Plot
- Box Plot
- Heatmap
- Pair Plot

### Task 7: EDA – Data Inspection & Cleaning (15 Marks)
- Inspect dataset rows, columns and data types.
- Generate statistical summaries.
- Identify and handle missing values.
- Detect and remove duplicate records where required.
- Check incorrect or inconsistent values.
- Compare the dataset before and after cleaning.

### Task 8: EDA – Correlation & Insights (10 Marks)
- Perform correlation analysis.
- Identify relationships between variables.
- Analyze patterns and trends.
- Generate at least 3 meaningful insights.

### Task 9: Business Recommendations (5 Marks)
- Provide at least 2 data-driven business recommendations.
- Explain how the recommendations are supported by the analysis.

- Apply descriptive statistical techniques.
