
# Excel – Statistics & Exploratory Data Analysis

This folder contains Excel workbooks and supporting files prepared for Week 4 of the InternNova Data Analytics Internship.

## Topics Covered

### Statistical Analysis
- Mean
- Median
- Mode
- Variance
- Standard Deviation

### Correlation & Probability
- Correlation analysis
- Understanding relationships between variables
- Basic probability calculations

### Data Analysis
- Data inspection
- Sorting and filtering
- Identifying missing values
- Detecting duplicate records
- Checking inconsistent values
- Data cleaning

### Data Visualization
- Charts and graphs
- Data distribution
- Identifying patterns and trends
- Supporting statistical analysis through visualizations

### Insights & Recommendations
- Identifying meaningful patterns in datasets
- Supporting analytical findings
- Providing data-driven business recommendations

## Tool Used
- Microsoft Excel

## Objective
To apply statistical calculations, organize and analyze data, identify patterns and support exploratory data analysis using Microsoft Excel.

## Learning Outcomes
- Calculate descriptive statistics.
- Understand data variability.
- Analyze relationships between variables.
- Inspect and clean datasets.
- Interpret data and support business decisions.
