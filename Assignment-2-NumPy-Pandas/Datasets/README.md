
# Datasets – Assignment 2

This folder contains the CSV datasets used for the NumPy and Pandas Data Analytics assignment.

## Dataset Files

- `sales_data.csv` – Sales transaction dataset.
- `employees.csv` – Employee information dataset.
- `orders.csv` – Customer orders dataset.

## Purpose

These datasets are used to practice:

- Reading CSV files using Pandas.
- Inspecting and understanding datasets.
- Filtering and sorting records.
- Handling missing values.
- Merging and concatenating DataFrames.
- GroupBy and Pivot Table operations.
- Performing basic data analysis.
