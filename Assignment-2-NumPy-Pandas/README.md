
# Assignment 2 – NumPy and Pandas for Data Analytics

## Internship
InternNova – Python and Data Analytics Internship

## Week 2 Assignment

**Topic:** NumPy & Pandas for Data Analytics

**Duration:** 7 Days

**Total Marks:** 100

**Submission Deadline:** 19 November 2026

## Objective

To develop practical skills in NumPy and Pandas, including numerical operations, array manipulation, dataset inspection, data cleaning, filtering, sorting, merging, grouping, pivot tables and data export.

## Tasks Covered

1. NumPy Introduction and Arrays
2. NumPy Indexing, Slicing and Reshaping
3. NumPy Mathematical and Statistical Operations
4. Pandas Series and DataFrame
5. Reading and Inspecting Data
6. Selecting, Filtering and Sorting Data
7. Handling Missing Values
8. Merge, Concatenate, GroupBy and Pivot Table
9. Exporting Data
10. Mini Data Analysis Project

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Visual Studio Code

- Create and manipulate NumPy arrays.
- Perform mathematical and statistical operations.
- Work with Pandas Series and DataFrames.
- Inspect and clean datasets.
- Filter and sort records.
- Merge and concatenate datasets.
- Perform GroupBy and Pivot Table analysis.

- Generate meaningful insights from data.
